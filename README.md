# Raptor Pro — Downloads

Money-management software for Spribe Aviator. Windows 10 / 11, 64-bit.

## Download

**[Latest release](../../releases/latest)**

## Requirements

- Windows 10 or 11, 64-bit
- Google Chrome installed
- A Raptor Pro licence (a free trial is available in the app)
- 8 GB RAM, ~250 MB disk, 1366×768 or larger screen
- An account with a supported Spribe Aviator operator

## Installation

Unpack the ZIP to a folder you can write to, such as `C:\RaptorPro`.
Avoid `C:\Program Files` — it blocks the app from saving its settings.
Keep the folder together and run `RaptorPro.exe`.

## Documentation

Full handbook, settings reference and troubleshooting: https://raptorpro-handbook.netlify.app

## Important

Raptor Pro automates bet sizing, cash-out targets and stopping rules.
It does **not** predict multipliers and cannot influence the outcome of
any round. Every round is independent. **No profit is guaranteed** and
losses, including the loss of your entire balance, are possible.
